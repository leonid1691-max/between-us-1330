# Между нами 1330 км

Романтическая игра для Лёни и Даши. В общей комнате доступно ровно три задания в день по московскому времени. Каждое задание засчитывается только после подтверждений обоих игроков. Новая комната начинает отсчёт в день создания; финальные объятия и нулевое расстояние запланированы на 24 октября 2026 года.

## Supabase

1. Создайте проект на [supabase.com](https://supabase.com/).
2. Откройте **Project Settings → API Keys** и скопируйте **Project URL** и **Publishable key**.
3. Вставьте значения в `config.js`:

   ```js
   window.BETWEEN_US_CONFIG = {
     supabaseUrl: 'https://ВАШ-ПРОЕКТ.supabase.co',
     supabasePublishableKey: 'ВАШ_PUBLISHABLE_KEY'
   };
   ```

   Publishable key рассчитан на браузерное приложение. Никогда не помещайте `secret` или `service_role` key в клиентский код.

4. В Supabase откройте **SQL Editor → New query**, вставьте файл `supabase-setup.sql` и нажмите **Run**. Если SQL уже был применён, выполните обновлённый файл повторно: он добавляет календарные поля в существующую таблицу и обновляет RPC-функции.

## Загрузка на GitHub Pages

Загрузите в корень репозитория последние версии `index.html`, `config.js`, `sync.js`, `dasha.svg` и `lenya.svg`. README и SQL-файл также можно хранить в репозитории. Включите **Settings → Pages → Deploy from a branch → main → /(root) → Save**. После коммита GitHub Pages опубликует обновлённую версию.

## Создать комнату и пригласить Дашу

1. Откройте сайт как Лёня, нажмите **Пригласить второго → Создать общую ссылку для Даши**.
2. Отправьте Даше созданную ссылку. В комнате у тебя будет роль Лёни, у неё — Даши.
3. Ежедневно вам доступны три задания. Первое подтверждение отмечается, но не меняет расстояние; после подтверждения второго игрока общий прогресс сохраняется в Supabase.
4. При создании комнаты 1330 метров распределяются равномерно по доступным заданиям. По три задания открываются каждый день по московскому времени; последний шаг приводит к нулю 24 октября.

Ссылка комнаты служит приглашением для обоих игроков. Не публикуйте её открыто, если хотите оставить игру личной.
