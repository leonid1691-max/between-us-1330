# Между нами 1330 км

Романтическая игра для Даши и Лёни. GitHub Pages размещает интерфейс, а Supabase хранит общий прогресс комнаты.

## Подключить общий прогресс

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/).
2. В Supabase откройте **Project Settings → API Keys** и скопируйте **Project URL** и **Publishable key** (или старый ключ `anon`, если он отображается).
3. Откройте `config.js` и вставьте их в поля:

   ```js
   window.BETWEEN_US_CONFIG = {
     supabaseUrl: 'https://ВАШ-ПРОЕКТ.supabase.co',
     supabasePublishableKey: 'ВАШ-ПУБЛИЧНЫЙ_ANON_КЛЮЧ'
   };
   ```

   Публичный anon key предназначен для браузерного приложения. Не вставляйте сюда `service_role` key.

4. В Supabase откройте **SQL Editor → New query**, вставьте содержимое файла `supabase-setup.sql` и нажмите **Run**.
5. Загрузите обновлённые файлы в корень GitHub-репозитория и опубликуйте их через GitHub Pages. Нужны `index.html`, `config.js`, `sync.js`, `dasha.svg` и `lenya.svg`; README и SQL-файл можно также сохранить в репозитории.

## Начать общую игру

1. Откройте сайт. Нажмите **Пригласить второго → Создать общую ссылку для Лёни**.
2. Скопируйте появившуюся ссылку и отправьте её Лёне. У Даши и Лёни откроется одна комната.
3. Первый игрок нажимает **«Мы сделали это»** — его подтверждение сохраняется. Расстояние пока не меняется.
4. После подтверждения второго игрока общий прогресс уменьшается, и оба браузера получают обновление. Страница проверяет изменения автоматически примерно каждые две секунды.

Если открыть страницу без общей ссылки, доступен локальный режим для проверки: одно нажатие отмечает готовность Даши, следующее — Лёни. Общая ссылка создаёт отдельную комнату с новым прогрессом.

Комната доступна участникам по ссылке-приглашению. Не публикуйте её в открытом доступе, если хотите оставить игру личной.

## Публикация на GitHub Pages

1. Войдите на [github.com](https://github.com/) и создайте репозиторий (**+ → New repository**).
2. Назовите репозиторий, например `between-us-1330`, выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Перетащите нужные файлы из папки `between-us` в корень репозитория и нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
7. Через пару минут адрес появится на странице Pages, например `https://ВАШ-ЛОГИН.github.io/between-us-1330/`.

Если GitHub использует другую главную ветку, выберите её вместо `main`.
